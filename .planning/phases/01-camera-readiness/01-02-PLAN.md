Use the plan 01 shared observation/controller and runtime validator; no general bridge framework. Readiness uses a distinct fixed event such as `physiquequest-camera-readiness`, leaving `physiquequest-pose` rep messages unchanged. Envelope types are observation/reset/error/capability and contain bounded session identity; observations contain frame identity, source/preview geometry, mirroring, full landmarks and optional scalar luminance.
