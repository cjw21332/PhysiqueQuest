# Local evaluation (experimental)

`run_eval.mjs` is an offline developer tool; it is not imported by the application. Enable it explicitly with `POSE_EVAL_ENABLED=1` and pass local JSON files to Node. Inputs contain `exerciseId`, `config` (the generic counter configuration), `frames` (timestamped `PoseFrame` objects), and `groundTruth` with integer `reps`, `partialWindows` and `faultWindows` arrays of `{startMs,endMs}`. Times use the frame timestamp clock. The evaluator matches each emitted event to at most one labelled interval. A null precision or recall denotes an undefined denominator. Only independent, held-out participants can support the proposed within-one-repetition target.

Recordings must be consented, local only and use random participant codes; no video or images. The `recordings` and `reports` directories are git-ignored. This repository does not yet provide the requested consent-gated recorder or automated deletion command. Do not collect participant data with this tool until those controls are implemented. No classifier is trained. A future classifier input may consist of versioned timestamped normalized landmarks, visibility masks, exercise identifier and independently labelled event intervals; its model and validation procedure remain unspecified.
