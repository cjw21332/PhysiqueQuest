# Native tracker 20-minute test protocol — NOT READY TO RUN

The native telemetry toggle and JSON export are not implemented yet. This protocol is a planned run, not evidence of phone behavior. Do not treat a session without the debug log as a completed telemetry test.

After native telemetry, persistent activation, export and the APK rebuild have been verified, run this session in a safe workout setting with an appropriate load and normal rests. Keep a separate clock:

| Time | Action |
| --- | --- |
| 0:00–3:00 | Machine chest press, back camera. Include several sets and rests with the working arms visible. |
| 3:00–6:00 | Machine preacher curl, back camera. Pause for normal rest. |
| 6:00–9:00 | Rear pull-up or assisted pull-up, back camera, if equipment is available and comfortable. |
| 9:00–11:00 | While paused or safely between sets, background the app for 30 seconds, then return. Record the text and time at each transition. |
| 11:00–14:00 | Shoulder press; switch from back to front camera between sets, and then switch back. |
| 14:00–17:00 | Bench press, back camera; choose a position with arms visible and note any plate occlusion. |
| 17:00–20:00 | Return to preacher curl or chest press, using a front camera view if practical; complete normal rests. |

At each minute or event, note by hand whether the screen dimmed, whether the device felt warm, whether a black screen appeared, the exact on-screen message, camera switches, pauses, and unplanned camera recovery. Stop the session if the device becomes uncomfortably warm or an exercise feels unsafe.

Export location and activation instructions are **not yet established**. Once implemented, update this file with the tested Android and iOS save/share paths before running. The JSON should contain timing, recovery and environment metadata; do not include camera video or landmarks in the telemetry export.
