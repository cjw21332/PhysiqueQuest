# Scan and nutrition

The Nutrition dashboard shows the day's meals and totals, meal editing, water intake, a food history link, and a dietary plan. The old `/scan/today` address redirects to the dashboard.

The camera and photo picker both prepare an image locally before sending it for food recognition. The review screen lets users correct the foods and weights, include or exclude items, select a meal and adjust a global portion multiplier. Nutrition values that cannot be matched remain unavailable. Saved scans use a receipt so an uncertain save can be checked and recovered.

Food search currently uses USDA records. Additional Philippine and packaged-food sources are not yet connected.
