# Food scanner real-image evaluation

Status: not performed. Controlled mocks do not establish recognition, nutrition-match, or weight accuracy.

Before deployment, collect consented photographs of real meals, with a separate kitchen-scale measurement for each edible food as served and a record of its preparation, ingredients, sauces, and selected USDA record. Include single foods, two separate foods, three or more foods, overlaps, mixed dishes, Filipino meals, dim lighting, blur, varied plate sizes, and varied camera angles. Split by meal and photographer so near-duplicate photographs never cross development and evaluation sets. Record exclusions and obtain permission for storage and use of images.

For each photograph, independently annotate visible food identities, omissions and extras. Compare matched foods using a predeclared matching protocol; report precision and recall with counts and confidence intervals, by image category. Report ambiguous or unidentifiable foods separately. For matched foods, report signed and absolute weight error in grams and median absolute percentage error where measured mass is nonzero, including results for overlapping foods. Compare selected USDA records with a dietitian-reviewed reference, noting raw/cooked and preparation mismatches. Calculate meal-level calorie and macro errors from measured quantities and reference records; report incomplete nutrients separately, never as zero. If a segmentation model is introduced, annotate regions and report instance matching and intersection-over-union independently of identification.

Record model and prompt versions, image preprocessing, model parameters, dates, provider responses, latency, retries, token counts when provided, and published rates in effect. Keep a held-out test set and report every failed or timed-out scan. Compare candidate models on the same images, including cost and latency, before changing the default. Test corrections and saved records on web and physical mobile devices against an isolated test account and configured providers. No accuracy or cost figures are claimed until those measurements exist.
