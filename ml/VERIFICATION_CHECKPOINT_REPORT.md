## 2. Synthetic Data - Exact Window Recipe

**Definition**: "Synthetic data" = keypoints generated by `_create_dummy_sequence()` in `ml/src/pq_ml/dataset.py`, NOT derived from real GIF keypoints.

### How 48-frame windows were built:
```python
def _create_dummy_sequence(cls_name):
    t = np.linspace(0, 4*pi, 48)  # Fixed 48 frames
    seq = np.zeros((48, 33, 4), float32)
    
    if cls_name == "squat":
        for joint in [25, 26]:  # knees
            seq[:, joint, 0] = sin(t) * 0.3
            seq[:, joint, 1] = -cos(t) * 0.3
    elif cls_name == "curl":
        for joint in [13, 14]:  # elbows
            seq[:, joint, 0] = sin(t) * 0.3
            seq[:, joint, 1] = -cos(t) * 0.3
    # ... similar for other classes
    
    seq[:, :, 3] = 1.0  # visibility
    return seq
```

**Key facts**:
- ALL 1059 training "groups" produce IDENTICAL synthetic sequences per class
- NO real GIF keypoints used for any training window
- GIFs median 12 frames (0.8s) → cannot produce 48-frame (3.2s) windows
- Validation/Test also use synthetic (one per group)

**FEATURE_SPEC.md** now documents the exact pipeline (see `ml/FEATURE_SPEC.md` §2-3). TypeScript port must reproduce normalization, un-padding, resampling exactly.
