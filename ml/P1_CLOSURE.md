# P1 closed: GIF tiling is not an evaluation gate

The tile test is diagnostic only, not accuracy; GIFs are not closed loops.
The four-of-five pattern is a GIF seam artifact, not a demonstrated counter bug.
Tile exact-match counts must not gate releases, config acceptance, or model
acceptance, and must not be optimized. Do not run this diagnostic again.
Existing reports are historical artifacts, not accuracy evidence.

Future counting evaluation uses annotated real videos, with configuration fixed
before examining test results. No joint-selection work is authorized here.
